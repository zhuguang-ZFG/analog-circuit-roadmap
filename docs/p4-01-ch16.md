<a id="sec-16-1"></a>
### 16.1 五步法详解

**① 症状确认——先看再做，先问再拆**

上手前先问 5 个问题：一直坏还是偶发？温度相关吗？上电瞬间坏还是运行后坏？带载才坏？**最近改过什么？**

- 🧠 **为什么**：偶发故障 80% 是焊接/连接问题；"最近改过"是最高产线索——故障往往随变更引入
- 🔧 **案例**：设备偶发复位，空调房里正常、机箱盖合上 10 分钟后出现 → 温度相关 → 热风枪逐区域加热，晶振焊点一吹就复位 → 虚焊，5 分钟收工

**② 二分定位——对数收敛，不要乱枪打鸟**

信号链中点测一下：好 → 故障在后半段；坏 → 在前半段。$n$ 个串联节点，最多 $\lceil\log_2 n\rceil$ 次测量定位。

- 🧠 **为什么**：6 级放大链只需 3 次测量；随机乱查的期望次数是其 2 倍以上
- 🔧 **技巧**：不必死守几何中点——从"最可疑 × 最易测"的节点下刀（电源、连接器、最近焊过的地方优先）

**③ 假设验证——一次只改一个变量**

每改一处前记录原始状态（拍照/记下阻值档位）；设计实验时想"什么结果能**证伪**我的假设"，而不是找支持证据。

- 🔧 **案例**：怀疑运放损坏，换新后故障依旧 → 假设被证伪，及时回头 → 实则是反馈电阻虚焊。很多人换完芯片故障还在，就"再换一颗试试"——这是排故头号时间杀手

**④ 修复——修根因，不是修症状**

保险丝烧了，先找**为什么烧**再换；换件先断电；烙铁 320~350°C，单点加热 &lt;3 秒；贴片件焊完用洗板水清掉助焊剂残留（吸潮漏电）

**⑤ 回归测试——修好不算完，跑过才算**

全温（冷冻喷剂+热风枪走一遍）、全程（老化 24h）、全工况（额定负载上下拉偏）；写维修日志：症状/根因/解法/复发率——这是团队最值钱的知识资产

### 16.2 思维工具箱：老手的四个暗器

| 暗器 | 做法 | 什么时候用 |
|---|---|---|
| **内外归因** | 先换"已知好的"电源/线缆/传感器，把故障域切到板内或板外 | 开工第一步，30 秒排除一半嫌疑 |
| **对比法** | 有一块好板就并排同点测量——**差异即线索** | 量产批次不良、玄学故障 |
| **极限法** | 电压拉偏 ±10%、温度吹风/冷冻，把偶发故障**逼成必现** | 偶发故障（不现形就没法测） |
| **隔离法** | 断开疑似负载/后级，看前级是否恢复 | 短路、过载、闩锁定位 |

### 16.3 测量本身不破坏电路（Jim Williams 铁律）

<p align="center"><img src="assets/svg/probe-loading.svg" width="720" alt="探头负载与测量破坏电路SVG动画"></p>

🔗 [动画演示 5.49](p5-00-part5.md#demo49)

- **探头是负载**：示波器 ×1 档 1MΩ‖~100pF，测高阻节点直接压垮电路——测模拟节点一律 ×10 档（10MΩ‖~10pF）
  🧮 **算一笔**：源阻 100kΩ 的节点挂 ×1 探头，分压系数 $1\text{M}/(100\text{k}+1\text{M})=0.909$——**误差 9%**，
  而且 $100k\times100pF=10\mu s$ 把截止频率压到 16kHz，高频信号直接被削圆。换 ×10 档：误差 1%、$f_c$ 提到 159kHz。
- **电流档=短路**：万用表电流档内阻≈0，并联到电源两端=放炮。测完电流**立刻把表笔插回电压孔**——肌肉记忆保命
- **上电先限流**：新板第一次上电串限流灯泡或用恒流模式电源（限 50mA）——短路板子冒的是灯泡的烟，不是芯片的
- **地线最后接**：示波器探头地夹与市电共地，测市电相关电路会短路——要么隔离变压器，要么差分探头

🧮 **算一笔**：一次典型排故的时间账——乱换两颗芯片 ≈ 40 分钟 + 拆焊损伤风险；先花 5 分钟问"最近改过什么"+二分测量，八成 15 分钟内定位。**最贵的是你手上的烙铁，最便宜的是嘴上的问题。**

<a id="sec164"></a>
### 16.4 一份完整的排故记录模板 + 复盘

> 排故的终点不是"修好了"，而是**这份经验下次能复用**。五步的产出如果只留在脑子里，团队就永远在重新踩同一个坑——**记录不是形式，是知识资产。**

**一张能直接抄的表**（每个故障填一行，附件放波形截图/照片）：

| 字段 | 填什么 | 为什么值钱 |
|---|---|---|
| **编号 / 日期** | F-2026-014 / 10-07 | 便于检索与统计复发率 |
| **症状** | 客观描述 + 复现条件（"带载 1A、机箱盖合上 10 分钟后偶发复位，空载不复现"） | 复现条件是二分定位的起点 |
| **现象波形** | 示波器截图（含时基/量程）+ 测量点 | 波形比文字精确一百倍 |
| **假设链** | 当时的所有怀疑及排序，逐条标"已证伪/已证实" | 证伪过程本身就是知识 |
| **根因** | 一句话说清"物理上到底发生了什么"（如"晶振焊点虚焊，热胀后接触电阻变大导致起振失败"） | 根因 ≠ 症状，必须落到物理机制 |
| **修复** | 具体动作（"补焊 + 改钢网开口"） | 可复制的操作 |
| **验证** | 做了哪些回归（全温/全工况/老化时长）与结论 | 防止"假好" |
| **复发率 / 后续** | 同类故障是否再现、是否已进设计评审清单 | 闭环的最后一环 |

**复盘三问**（团队周会上过一遍）：

1. **根因能归到设计约束吗？** 能 → 写进 [18.4 设计评审清单](p4-03-ch18.md#ch18)（如"晶振焊盘加长 + 钢网开口放大"）；不能 → 说明还停在"现象层"。
2. **这次花了多久？瓶颈在哪？** 是"没问最近改过什么"，还是"没做二分"？——**记录时间分配，才能优化排故流程本身。**
3. **下次能提前发现吗？** 有没有可加的自检、测试点或上电指示灯？**把一次故障变成一次"防呆设计"。**

🧮 **算一笔**：一个 20 人硬件团队，若每人每年遇 10 个故障、平均每次 2 小时——全年 4000 人时。**记录 + 复盘能把"重复故障"砍掉一半**，等于每年省出 2000 人时（≈ 1 个全职工程师）。**这就是为什么大师的工作台上永远有笔记本。**

<a id="sec165"></a>
### 16.5 排故实战演练：三个完整案例

方法论讲完了，但**方法只有在具体故障上跑一遍才算真的会**。下面三个案例，一个来自设计、一个来自环境、一个来自工艺——每个都按 [16.1 五步法](p4-01-ch16.md#ch16) 走完，并附复盘。注意它们的**共同结构**：五步走的骨架一模一样，而**卡壳的地方从来不是技术，是"没先问对问题"**。

#### 案例一：低温才自激 —— 相位裕度被容差吃掉

**现象**：某传感器板的 LDO 输出，室温 25℃ 全部正常；放进 -20℃ 老化箱，10 块里有 3 块输出上出现 ~150kHz 的**持续正弦振荡**。

| 步骤 | 动作与发现 |
|---|---|
| ① 问 | **只在低温出现** → 装配问题是随机的、不挑温度，先排除装配。再问"最近改过什么"——为了降成本，把输出电容从 **22µF 钽电容换成了 22µF MLCC**。 |
| ② 看 | 弹簧地针测 LDO 输出：150kHz、约 80mV 的**连续正弦**（不是随机噪声）→ 判定是**环路振荡**，不是外部干扰。 |
| ③ 二分 | 断开后级负载 → 振荡消失；接回 → 复现 → 锁定在 **LDO + 输出电容**这个环路。 |
| ④ 单变量 | 只换回钽电容 → 消失。再测环路相位裕度：**室温 58°，-20℃ 只剩 32°**（低于 45° 的工程下限）。 |
| ⑤ 根因 | LDO 的环路稳定性靠输出电容的 **ESR 零点**补相位。MLCC 的 ESR 只有几 mΩ（钽电容 200mΩ 级），零点跑到高频去了，**相位裕度就没了**；MLCC 的容值在低温下还会再掉 10~15%，雪上加霜。 |

**修复**：输出电容串 **0.15Ω**（人为造回一个零点），或选 datasheet 明确写"stable with ceramic output capacitors"的 LDO。
**回归**：10 块板跑 -40~85℃ 全温区 48h，无振荡。
**复盘三问**：① 能归到设计约束 → 写进 [18.4 设计评审清单](p4-03-ch18.md#ch18)：**"换电容类型前必须重看环路稳定性"**；② 瓶颈是"没先问最近改过什么"，绕了 2 小时才想到换料；③ 防呆：**所有"降成本换料"都要过一遍参数敏感性审查**。

#### 案例二：台架好好的，装进机箱就挂 —— 热 + 耦合

**现象**：24V 电机控制板，实验室裸板连续跑 8 小时无事；装进金属机箱盖好盖子，2 小时内 MCU 复位。**开盖就正常。**

| 步骤 | 动作与发现 |
|---|---|
| ① 问 | 开盖 vs 关盖差在哪？→ **温度 + 屏蔽**。先用红外热像仪量：关盖后 MCU 附近从 45℃ 升到 **68℃**。 |
| ② 看 | 抓复位瞬间的电源轨：3.3V 上有 **400mV、20ns 的尖峰**（不是塌陷）→ 是**干扰耦合**，不是供电不足。 |
| ③ 二分 | 给 MCU 电源加 π 滤波 → 尖峰减半但没消；**把晶振用铜箔罩住 → 尖峰消失** → 锁定晶振。 |
| ④ 单变量 | 查走线：晶振线长 12mm，与 MOS 开关节点（SW）**平行走了 6mm**。 |
| ⑤ 根因 | **两个因素缺一不可**：温度升 23℃ 让晶振的负阻裕度下降（[13.10 晶体振荡器](p2-03-ch13.md#ch13)），起振变得勉强；同时 SW 节点的高 dV/dt 通过平行走线的杂散电容耦合进晶振引脚，把勉强的振荡**打停一拍**——MCU 就跑飞了。 |

**修复**：① 晶振紧贴 MCU、走线 < 5mm、下方开地、四周地环；② SW 节点面积最小化 + RC 缓冲（snubber）；③ 选低 ESR 晶体提高负阻裕度。
**复盘三问**：① 写进清单：**"高 dV/dt 节点（SW、栅极、整流）与高阻节点（晶振、反馈、基准）必须物理隔离"**；② 瓶颈是"只怀疑温度"——**热像仪是本案的关键工具**；③ 防呆：**开关节点走线做一次寄生耦合审查**。

#### 案例三：批量"随机"复位 —— 其实是虚焊

**现象**：首批 1000 块，20 块（2%）偶发复位，**无温度规律、无时间规律**，用户反映"拍一下桌子就好了"。

| 步骤 | 动作与发现 |
|---|---|
| ① 问 | 复位有规律吗？→ 无规律 + "拍桌子就好" = **强烈的机械问题信号**。 |
| ② 看 | 复位引脚上有 **100ns 的负毛刺** → 确实被拉低过，不是软件跑飞。 |
| ③ 二分 | **敲击 / 扭板能复现** → 机械接触问题。X-Ray 看 BGA：**焊球有空洞、未润湿**。 |
| ④ 单变量 | 同批板重新回流（补焊）→ 20 块全部正常。 |
| ⑤ 根因 | BGA 焊球**虚焊**（冷焊）：钢网开口偏小 + 回流预热不足 → 焊球与焊盘只有**部分连接**，机械应力（热循环、振动）后就断开。 |

**修复**：① 钢网开口按焊盘 1:1（BGA **不要**缩开口）；② 调回流曲线（延长预热、提高峰值）；③ X-Ray 抽检；④ 设计上把 BGA 的未用球接地，增加机械强度。
**复盘三问**：① 写进 DFM 清单：**"BGA 钢网开口与回流曲线必须固化并留档"**；② 瓶颈是"先入为主以为是电气问题"，2 天后才做敲击试验；③ 防呆：**首件必过 X-Ray**，量产抽样加"机械应力 + 复测"。

**把案例一填进 [16.4 的模板](p4-01-ch16.md#sec164)**：

| 项 | 内容 |
|---|---|
| 故障现象 | -20℃ 下 LDO 输出 150kHz 自激，10 块 3 块 |
| 复现条件 | 低温 + MLCC 输出电容 |
| 隔离范围 | 断后级 → 消失；换回钽电容 → 消失 |
| 根因 | MLCC ESR 太低 → 环路零点移出 → 相位裕度 58°→32° |
| 修复 | 串 0.15Ω，或换陶瓷稳定型 LDO |
| 回归验证 | 10 块全温区（-40~85℃）48h 无振荡 |
| 防呆 | 换料必须重做环路稳定性评审 |

🧮 **算一笔（这三个案例值多少钱）**：案例三若流到客户手里，2% 的返修率意味着 1000 块要返 20 块，按每块返修 + 物流 200 元算就是 4000 元，还不算品牌损失；而首件 X-Ray 一次只要几十元。**"提前发现"的成本永远比"事后返修"低两个数量级**——这正是 [16.4 复盘三问](p4-01-ch16.md#sec164) 里第三问存在的理由。

> 💎 **精髓**：排故不是玄学，是"别骗自己"的流程学——先问后拆防臆断、二分砍半防乱枪、单变量防瞎换、修根因防治标、回归验证防假好；而**记录与复盘，是把一次性的"运气"沉淀成可复用的"方法"**。没有记录的排故，等于没排。

> 🎯 **通关打卡**：你现在拿到一块故障板，会先问 5 个问题、按对数切半定位、一次只改一个变量——而不是抓起烙铁就换芯片；修完还会填一张排故记录表、过一遍复盘三问，把这次的坑变成团队的免疫；**还能独立走完设计/环境/工艺三类故障各一例——从现象 → 隔离 → 根因 → 修复 → 回归，并填出一张完整排故记录表**。
