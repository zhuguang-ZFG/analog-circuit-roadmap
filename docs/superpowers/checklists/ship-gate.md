# 整包重做 · 五线上架总闸（Ship Gate）

> 来源：`docs/superpowers/specs/2026-11-03-full-remake-zero-to-engineer-design.md` §10.1–10.6 的可勾选副本。
> **任一线未完不得宣称整包完成。** 冻结规则：`make remake-ship` 未绿不得宣称整包完成；通过后仍不自动 push；发布走既有 pages 门禁。

## 10.1 章节内容线（docs）

- [ ] 结构六槽完整（进阶框可选）
- [ ] 口诀卡 1 张，且已登记总表同源
- [ ] ≥1 张 FA-029 手绘主图；图问 + 含数字读图指引
- [ ] ≥1 个可复现数值例；条件与出处齐全
- [ ] 验收清单可判定过关；设计类章指向 §4.2
- [ ] humanizer 已过；非白名单「不是…而是」为 0
- [ ] 无无出处死数字；示意已标明
- [ ] 锚点与 CONTRIBUTING 一致；跨页链接正确

## 10.2 站点线

- [ ] 由当前 `docs/` 构建；README 已重跑且与 CI 一致
- [ ] 侧栏目录、搜索、深浅色可用
- [ ] 动画画廊链接有效；章内动画回填不丢
- [ ] 每章页有主图位与自检入口
- [ ] 主站 https://zhuguang-ZFG.github.io/analog-circuit-roadmap/ 与镜像同内容版本号可核对
- [ ] 无画风漂移、无套话抽检失败页

## 10.3 书线（离线 HTML / 印刷 PDF）

- [ ] 正文从 docs 注入/生成，无平行书稿正文
- [ ] A4 PDF / 离线 HTML 均可打开；目录与章号对齐 ch0–18
- [ ] 印刷：出血/灰度下标注可读；动画信息按 v3.90 规则保留
- [ ] 色板与 HANDRAW-STYLE token 一致
- [ ] 版式检查清单勾完（沿用 10-24/10-25 已验证的工程项，不重新发明冲突规则）

## 10.4 视频线

- [ ] 分镜表与章口诀、主图隐喻、关键数值一致
- [ ] 旁白稿来自重写后 docs（可压缩句式，不改结论）
- [ ] 旁白音色偏好（若使用 TTS）：`edge-tts` `zh-CN-XiaoxiaoNeural`，语速 −5%，音高 −4Hz（温柔女声；与既有记忆一致，可被用户改口覆盖）
- [ ] SRT 完整；封面与章/集标记齐套
- [ ] 画面为手绘气质（FA-029 或同 DNA 渲染）；数值与封装路径真实
- [ ] 缺任一项 → 不出片

## 10.5 社媒线（公众号 / B 站 / 小红书）

- [ ] 切片文案结论与章验收清单一致
- [ ] 主视觉来自 yang0/handraw-style 流程且色板不打架
- [ ] 不新增未经 docs 收录的「新结论」「新数字」
- [ ] 每条可回溯到章号 + 口诀卡
- [ ] 平台尺寸裁切不裁掉关键标注

## 10.6 总闸（Ship gate）

- [ ] §10.1–10.5 全部勾完
- [ ] 无未决实施依赖、无「到时再说」式发布缺口
