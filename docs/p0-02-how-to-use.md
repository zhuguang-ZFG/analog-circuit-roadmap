## 🚪 如何使用本指南

| 你是谁 | 推荐路线 |
|---|---|
| **零基础小白** | [前言](p0-01-preface.md#preface) → [第 0 章](p1-01-ch0.md#ch0) 建立直觉 → [第 1 章](p1-02-ch1.md#ch1) 认识真实元件 → 每章**先看动画再做题** → [里程碑项目 1-2](p8-03-s8-3.md) 动手验证 |
| **有数电/单片机基础** | 直奔 [第 5 章 推挽开漏](p1-06-ch5.md#ch5)（痛点高发区）→ [第 12 章 运放电路族](p2-02-ch12.md#ch12) → [第 15 章 PCB](p3-02-ch15.md#ch15) |
| **工程师转模拟/复习** | [第 17 章 故障速查](p4-02-ch17.md#ch17) 当手册 → [第 11~13 章 拓扑](p2-00-part2.md#part2) 补原理 → [8.8 官方资料](p8-08-s8-8.md#sec88) 深入 |
| **时间紧只要精华** | [⭐ 必读精选](p0-05-picks.md#picks)——从 6 个常见问题切入，再按需要展开 |

每学完一章，先到 [自测题库](p9-00-quiz.md#part9) 找到对应章节，独立作答再展开答案。在线站的章末导航可以直接进入本章题目，也可以继续下一章；做错时用题目旁的“返回本章复习”补上原理。

**怎样判断自己学会了**：能说清现象、在明确条件下算出数量级、解释计算与仿真或实测的差异。先看懂答案只完成了第一步。
