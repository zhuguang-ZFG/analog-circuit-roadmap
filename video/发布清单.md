# 发布清单（第一季 · EP01–EP05）

> 成片都在 `video/samples/`：竖屏 `-final.mp4` 发抖音，横屏 `-final-h.mp4` 发 B 站，封面 `-cover.png`（1080×1920）两平台通用。发布包（标题/封面字/话题/置顶评论）在各集脚本末尾：`episodes/epNN-*.md`。

## 建议发布顺序

| 顺序 | 集 | 平台 | 文件 | 理由 |
|---|---|---|---|---|
| 1 | EP04 分压器带载 | 抖音 + B 站 | `ep04-divider-final(-h).mp4` | 钩子最直白（5V 塌 33%），有互动计算器可引流 |
| 2 | EP01 米勒平台 | 抖音 + B 站 | `ep01-miller-final(-h).mp4` | 「最贵的几百纳秒」，进阶受众转发率高 |
| 3 | EP02 虚短虚断 | 抖音 + B 站 | `ep02-virtual-short-final(-h).mp4` | 流量基本盘（运放第一课） |
| 4 | EP03 迟滞 | 抖音 + B 站 | `ep03-hysteresis-final(-h).mp4` | 彩蛋（迟滞+RC=振荡器）有传播点 |
| 5 | EP05 探头负载 | 抖音 + B 站 | `ep05-probe-final(-h).mp4` | 排故受众精准，涨粉质量高 |

## 每次上传三件事

1. **标题**：用该集脚本「标题候选」里的一条（抖音 ≤20 字悬念版；B 站 ≤30 字关键词版）。
2. **封面**：`samples/<name>-cover.png`；B 站横屏封面可从 `-final-h.mp4` 首帧截图。
3. **置顶评论**：书的链接（https://github.com/zhuguang-ZFG/analog-circuit-roadmap）+ 本集对应章节锚点 + 「评论区问题会回灌进书」。

## 话题标签（两平台通用）

`#模拟电路` `#电子DIY` `#嵌入式` `#硬件工程师` `#电赛` `#示波器`（按集增删）

## 数据复盘口径

- 抖音看**完播率**（目标 ≥45%）：不达标先砍前 3 秒，再砍中段
- B 站看**播放完成比**与**三连率**：不达标把算一笔段落加快 10%
- 评论区高频问题 → 开 Issue 回灌进书（这是这条内容飞轮的核心）

## 重出片命令备忘

```bash
# 竖屏成片（抖音）：分镜 → 口播 → 画面 → 母带
python video/narrate.py --shots video/shots/ep04-divider.json
python video/master.py  --shots video/shots/ep04-divider.json
# B 站横屏
python video/narrate.py --shots video/shots/ep04-divider.json --size horizontal
python video/master.py  --shots video/shots/ep04-divider.json --size horizontal
# 封面
python video/director.py --shots video/shots/ep04-divider.json --cover
```
