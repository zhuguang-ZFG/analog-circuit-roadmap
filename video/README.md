# 《模拟电路动画课》视频系列企划

> 把一本开源模电书，拆成**一分钟一坑**的动画短视频。抖音做钩子，B 站做深度，书做地基。

本目录是官方视频系列的**生产资料库**：企划、可拍摄级脚本、素材清单、发布包。成片上传后，把视频链接回填到 [p7-01-s7-1.md](../docs/p7-01-s7-1.md)（B 站表）即可在站点互通。

---

## 1. 为什么这个课能成

| 别人家 | 我们 |
|---|---|
| 静态 PPT + 鼠标圈圈 | **108 张自研 SMIL 动画**，四拍拆解（静态原理放成慢动作），直接录就是成片素材 |
| 拍脑袋给数 | 每个数字都能代回书里的公式复核（CI 里跑着 ngspice 仿真回归） |
| 讲完就散 | 每集挂书：完整推导、公式速查表、互动计算器、自测题，全部免费开源 |
| 版权灰区 | **CC BY-SA 4.0**，素材全部自产，随便剪随便二创 |

## 2. 双平台策略

| | 抖音 | B 站 |
|---|---|---|
| 定位 | 单坑钩子：一个坑 + 一句口诀 | 完整四拍：原理→模型→算一笔→翻车点 |
| 时长 | 45~90 秒，竖屏 9:16 | 3~6 分钟，横屏 16:9 |
| 节奏 | 前 3 秒给冲突，第 40 秒给口诀，结尾引流合集 | 前 30 秒给「你将搞懂什么」，中段动画慢讲，结尾挂书 |
| 字幕 | 大字压屏（关键词换色） | 底部常规字幕 + 关键数字放大 |
| 合集 | 《模拟电路动画课》按章建合集 | 按篇建合集（器件篇/拓扑篇/设计篇/排故篇） |
| 引流 | 置顶评论挂书链接与「下一集」 | 簡介挂书链接 + 章节分 P |

**内容母版是同一份**：每集脚本里先写 B 站完整版，抖音版是它的「前 90 秒压缩 + 大字重排」——先深后浅，而不是先浅后凑。

## 3. 制作管线

1. **选题**：从 [公式速查表](../docs/p0-08-cheatsheet.md) 的「翻车点」列和各章 🧮 算一笔里挑——**有冲突的选题才是好选题**。
2. **脚本**：按 `episodes/` 里的模板写，数字一律取自书里算例（逐字）。
3. **素材**：`assets/svg/*.svg` 是 SMIL 动画，浏览器打开即播。两条录制路线：
   - 快：**OBS 录屏**浏览器全屏（F11），按脚本节拍用「←/→」手动推进（SVG 内置左右箭头按钮可切拍）；
   - 稳：Playwright/Puppeteer 按 SMIL 时间轴自动录（`video/samples/` 有直录样片与做法）。
4. **配音**：人声优先（工程师口吻、语速 240~280 字/分钟）；TTS 备选（豆包/火山音色较自然，注意「运放/压摆率」等专业词读音校对）。
5. **剪辑**：剪映自动字幕 + 关键词大字换色；**数字出场时停 0.5 秒**（这是课，不是快剪）。
6. **发布**：每集脚本末尾的发布包（标题候选 / 封面字 / 话题 / 置顶评论）直接抄。

## 5. 发布包模板

每集脚本末尾自带，结构固定：

- **标题候选** ×3（抖音≤20 字带悬念；B 站≤30 字带关键词）
- **封面字**（≤8 字，一张 SVG 关键帧做底）
- **话题**：#模拟电路 #电子DIY #嵌入式 #硬件工程师 #电赛
- **置顶评论**：书的链接 + 本集对应章节锚点 + 「评论区问题会回灌进书（开 Issue）」
